### 🧠 About Me

I build software at two ends of the stack: **backend systems that hold up under load**, and **tooling that makes LLM-based systems measurable and trustworthy**. Recently I've been spending most of my time on the second — evaluation frameworks, hallucination detection, and benchmarking pipelines for LLM applications.

- ⚙️ Design distributed backend systems — concurrency control, atomic transactions, fault-tolerant queues
- 🔍 Build LLM evaluation infrastructure — judge models, hallucination detection, regression tracking
- 🏗️ Organized **DotSlash 8.0 & 9.0** (1000+ registrations) and **Echelon** (200+ teams) as Core Member, ACM SVNIT
- 📚 Completed a deep dive into LangChain, RAG pipelines, and agentic workflows
